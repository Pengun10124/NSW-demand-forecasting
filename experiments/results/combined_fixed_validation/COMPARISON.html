Interpretation and limitations

This predicts the daily minimum and the 10:00–15:00 minimum, not the full 48-point daily demand curve. The test period has already been inspected, so this is an exploratory comparison. Observed weather substitutes for forecasts; wind definitions differ between sources. Tuning and reporting use the same validation folds, not nested CV. Classification retains the full-training quantile threshold.
